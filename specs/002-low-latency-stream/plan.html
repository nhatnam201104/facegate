2. Đối chiếu 6 Nút thắt Gây Lag & Giải pháp Triệt tiêu

Nút thắt hiện tạiĐộ trễ cũGiải pháp mớiSau tối ưu
_render() nằm chung vòng lặp với _process() 70–220 ms khựng Tách sang StreamComposer đọc OverlaySnapshot bất biến 0 ms chặn
Pillow chuyển đổi BGR↔RGB toàn ảnh 960×540 6–10 ms / frame LabelSpriteCache LRU chỉ dựng mảnh chữ nhỏ ~200×24 ~0.25 ms
FFmpeg RTSP giữ jitter buffer mặc định 300–800 ms Cờ fflags;nobuffer|flags;low_delay|max_delay;250000 15–45 ms
run_in_threadpool mỗi frame + nén riêng ở video_raw Nghẽn worker AsyncIO FrameHub dùng chung 1 mảng byte JPEG cho N người xem 0 OS thread
Reverse Proxy gom buffer + mạng chậm gây trễ dồn Trễ tăng dần Header X-Accel-Buffering: no + nhảy thẳng tới hub.seq mới nhất Tự hồi < 2s
Tab ẩn vẫn mở /video.mjpg ngầm vĩnh viễn Tốn CPU/Băng thông syncVideoStreams() ngắt kết nối ngay khi đổi tab / ẩn cửa sổ 0% khi ẩn
